# Developer Experience Survey

## 📖 About the Project

This is a **Developer Experience Survey Form** created as part of my HTML and CSS learning journey.

The purpose of this project was to practice building web forms, understanding semantic HTML, and applying basic CSS styling. Through this project, I learned how to collect user input using different form elements and how to create a clean and responsive layout.

## 🚀 Features

* User-friendly survey form
* Full Name input field
* Email validation
* Number input with range validation
* Programming language dropdown menu
* Radio buttons for work preferences
* Checkboxes for tool selection
* Textarea for additional comments
* Submit button
* Basic responsive layout
* Beginner-friendly CSS styling

## 🛠️ Technologies Used

* HTML5
* CSS3
